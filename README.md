## How it is built

Plain static HTML, one stylesheet (`assets/css/main.css`) and one script (`assets/js/main.js`). The `main` branch holds the sources; pages are generated by a small Python script with no dependencies:

```
python3 _build/build.py        # writes the HTML, sitemap, search index and ads.txt
python3 _build/make_images.py  # optional: share image and icons (needs playwright)
```

- `_build/herbs.py` — herb data: names, temperament, graded uses, safety, interactions.
- `_build/extras.py` — concern hubs, glossary, videos, verified references.
- `_build/pages/` — page bodies (home, tools, forms, guides, legal pages).
- `_build/build.py` — layout, header and footer, herb and hub pages, search index, sitemap.

Generated files are git-ignored on `main`. Edit the data or a page body and push: the **Publish** workflow builds the site and publishes it to the `gh-pages` branch. All internal links are relative, so the same output works on github.io and on hakeem.com.

## Forms and the private inbox

Every form (consultations, listings, support pledges, contests, jobs, advertising, contact, newsletter, quiz results) is delivered to one private inbox through FormSubmit. The address is never written in the HTML, scripts or this repository; `main.js` assembles it only at the moment a form is sent.

**One-time step:** the first submission from a new domain triggers a FormSubmit activation email to that inbox. Open it and click **Activate** once for github.io and once again after the site moves to hakeem.com.

## Google AdSense

- Publisher ID `ca-pub-6620975821265271`. The loader script and `google-adsense-account` meta tag are on every content page.
- The loader is deliberately left off `404.html`, `consult.html`, `practitioners.html` and `support.html` so ads never sit next to conversion forms.
- `ads.txt` is at the site root. AdSense reads it only from the root of the approved domain, so apply with **hakeem.com** after the domain is connected.
- Auto ads place units automatically. To add manual units, create them in AdSense and put their slot IDs in `AD_SLOTS` in `_build/build.py` (`home-1`, `home-2`, `herb-mid`, `herb-end`, `hub-mid`, `guide-mid`), then rebuild.
- In AdSense, turn on **Privacy & messaging → European regulations** so EEA, UK and Swiss visitors get a Google-certified consent message.

## Publishing on GitHub Pages (free plan)

The repository is public, which the free plan requires. The **Publish** workflow (`.github/workflows/publish.yml`) runs on every push to `main`: it builds the pages, renders the share image and icons, and force-pushes the finished site to the `gh-pages` branch. GitHub Pages serves the site from `gh-pages` (root).

If Pages ever shows as disabled: **Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / root → Save.**

## Connecting hakeem.com

1. Add a file named `CNAME` containing `hakeem.com` at the repository root (the Publish workflow carries it into `gh-pages`).
2. At the domain registrar, set:
   - `A` records for `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` for `www`: `webworksa1.github.io`
3. In **Settings → Pages**, enter `hakeem.com` as the custom domain and tick **Enforce HTTPS** once the certificate is issued.
4. Re-activate FormSubmit for the new domain (see above) and submit `https://hakeem.com/sitemap.xml` in Google Search Console.
